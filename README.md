# 🩺 anamnesis - Accurate medical answers using patient data

[![](https://img.shields.io/badge/Download-Anamnesis-blue.svg)](https://github.com/arday5581-dev/anamnesis/releases)

Anamnesis connects patient health records to a smart chat interface. It acts as a clinical support tool that reads your medical data and answers questions based on facts. You get reliable answers with links to the original sources. This process prevents mistakes and keeps health information accurate.

## 📋 What this tool does

Doctors and medical teams often manage large amounts of health files. Finding specific details in that data takes time. This tool solves that problem through these features:

- Secure data streaming: It pulls health information from your systems.
- Vector search: It indexes your documents for fast retrieval.
- Verified answers: It uses current medical records to answer questions.
- Citations: It shows the exact document section used to create each answer.
- Reliable logic: It reduces errors by relying on provided data rather than outside guesses.

## 🗝️ How to use the chat

The application opens a window where you can type your questions. The system analyzes your medical data. It then presents a clear response. Under each response, you will see a list of files or records. Click these links to view the evidence behind the answer. 

If the application does not find information, it tells you that the records do not contain a match. This honesty helps you avoid bad clinical decisions. Always verify important information against the provided links.

## ❓ Common questions

**Does this replace a doctor?**
No. This tool assists clinicians by finding information faster. It does not provide a formal diagnosis. Always review the citations provided by the tool.

**What happens if I lose my internet connection?**
The tool requires internet access to process language queries. It will resume normal function once the connection returns.

**Can I export the chat history?**
Yes. You can save your conversations through the file menu. This helps you keep a record of the information shared during a clinical consultation.

**How do I update the software?**
Check the releases page once per month. Download the new installer and run it over your existing version. Your settings will remain unchanged.

## 💡 Best practices for queries

To get the best results, use specific language. Instead of asking "How is the patient?" use "What were the patient's glucose levels in the last report?" or "List the recent medication changes for this patient." These specific questions help the software narrow down the correct documents to show you.
